# Kairosplit: Divergent Timelines

"Unleash a dynamic temporal multiverse in Minecraft driven by player choices, localized timeline forks, and cross-era butterfly effects."

---

## 📌 О проекте (Concept Overview)

**Kairosplit** — это амбициозный open-source мод для Minecraft (NeoForge / Fabric API), добавляющий в игру механику динамических временных линий и хроно-парадоксов.

В отличие от классических измерений, мир в Kairosplit реагирует на масштабные действия игроков (разрушение биомов, уничтожение ключевых сущностей, постройка сверхструктур), создавая «Временные Разветвления» (Timeline Forks). Обычный мир может расколоться на альтернативные версии: от постапокалиптического синта-века до застрявшего в первобытном периоде мира, где физика и фауна полностью изменены.

### 🧠 Философия репозитория
Этот проект задуман как **Community-Driven Specification**. На данный момент здесь нет готового Java-кода. Цель этого репозитория — собрать команду разработчиков, архитекторов и геймдизайнеров для совместного проектирования и создания мода с нуля. Если у вас есть крутая идея для эпохи, аномалии или вы сильны в миксинах и асинхронных чанках — ваш вклад критически важен!

## 🚀 Основные особенности (Planned Features)

* **Энтропия и Парадоксы (Temporal Entropy Engine):** Каждое глобальное изменение мира повышает уровень местной энтропии. Высокая энтропия вызывает «хроно-штормы», искажающие блоки и спавнящие аномалии из других эпох.
* **Параллельные Временные Слои (Timeline Layering):** Игроки могут перемещаться между локальными фазами одного и того же пространства (например, прошлым, настоящим и разрушенным будущим конкретной деревни) с помощью Chrono-Anchors.
* **Эффект Бабочки (Cross-Era Logic):** Изменение прошлого в специальной локации (например, посадка древнего древа) мгновенно пересчитывает чанки в будущем этой фазы.
* **Модульная Архитектура Эпох (Plug & Play Eras):** Каждая эпоха (Past, Far Future, Cyber-Apocalypse, Prehistoric) — это самостоятельный модуль, содержащий собственные правила генерации, мобов и лут.

## 🛠️ Планируемый Технологический стек (Tech Stack)

* **Язык:** Java 17 / 21
* **Платформы:** NeoForge & Fabric (с использованием Architectury API)
* **Сборка:** Gradle
* **Тестирование:** JUnit 5, Minecraft GameTest Framework
* **Асинхронность:** CompletableFuture, Custom Thread Pooling для просчета энтропии чанков
